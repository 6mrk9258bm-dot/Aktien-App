Aktien Dashboard
Eine interaktive Web-App zur Visualisierung von Börsenkursen, gebaut mit Streamlit und Python.
![Python](https://img.shields.io/badge/Python-3.9+-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.0+-red)

Features
Beliebige Aktien per Symbol suchen (z.B. AAPL, TSLA)
Interaktiver Candlestick-Chart (Einzelaktie) & Linienvergleich (mehrere Aktien)
Gleitende Durchschnitte: MA50 & MA200
Kennzahlen: Aktueller Kurs, Höchst- & Tiefstkurs
Aktuelle News zu gesuchten Aktien

Tech Stack
Python: Programmiersprache
Streamlit: Web-Interface
yfinance: Echtzeit-Börsendaten (Yahoo Finance API)
Plotly: Interaktive Charts
Pandas: Datenverarbeitung

Installation & Nutzung
1. Repository klonen:
   git clone https://github.com/DEIN-USERNAME/aktien-dashboard.git
   cd aktien-dashboard
3. Virtuelle Umgebung erstellen & aktivieren:
   python3 -m venv .venv
   source .venv/bin/activate
4. Pakete installieren:
   pip install -r requirements.txt
5. App starten:
   streamlit run app.py
